# Contribuindo com o SCAF Hub

O Hub aceita contribuições que melhorem clareza, acessibilidade, performance, documentação e manutenção do projeto.

## Antes de abrir uma mudança

- para bugs, use o formulário de Bug report;
- para ideias, use o formulário de Sugestão;
- não publique builds, assets ou conteúdo oficial sem autorização da equipe;
- não inclua tokens, chaves, cookies ou outros segredos no repositório.

## Front-end

O site usa Astro e CSS próprio. Mudanças devem preservar navegação por teclado, estados de foco, layout mobile e `prefers-reduced-motion`.

## Conteúdo

Estados como `PÚBLICO`, `TEST BUILD`, `PLANEJADO` e `BLOQUEADO` têm significado. Não apresente uma build de teste como release e não invente datas de lançamento.
